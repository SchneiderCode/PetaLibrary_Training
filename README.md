# Template_Liascript_Repo

Steps to creating a new Liascript Tutorial: 

1. Create a new repository using this template repo
2. Update this ReadMe to include the following:
   * The course's name
   * A description of the course's focus area and a bulleted list of key topics  
3. Update the "training.md" file to include the course's content
4. Add any images or media files to the "/img" directory
5. Ensure all content meets the [CURC Accessibility Guidelines](https://curc.readthedocs.io/en/latest/additional-resources/contrib_curc_docs.html#curc-documentation-guidelines)
6. Preview the training with the current Research Computing fork of Liascript:
   * Base URL: `https://researchcomputing.github.io/liascript/course/`
   * Course's Markdown file: `https://github.com/ResearchComputing/<training repo>/blob/main/training.md`
   * Combined URL (one line, no spacing):
     * `<Base URL>?<Markdown URL>`
     * `https://researchcomputing.github.io/liascript/course/?https://github.com/SchneiderCode/New_User_Async_Training/blob/main/new_user.md`
8. Once the course is complete, add it to the [CURC Documentation's Online Training Page](https://github.com/ResearchComputing/Documentation/blob/main/docs/getting_started/trainings_and_consults/online-trainings.md)

**Do not remove the accessibility notice below!**
